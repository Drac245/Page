# Mundilácteos: rediseño del sitio web

Trabajo de auditoría y conceptos para el nuevo sitio de mundilacteos.com.

- `auditoria/`: auditoría del sitio actual y de competidores (informe, hallazgos, capturas y datos).
- `conceptos/`: los dos conceptos de sitio (dirección visual y prototipos navegables).
- `conceptos/compartido/`: recursos comunes (imágenes tomadas del sitio actual del cliente, datos de catálogo).
- `presentacion/`: página de presentación que reúne todo.
